# Plan — REQ-DEMO-001@v3, REQ-DEMO-002@v2 (CHG-0002, add a Subtract button)

Slice 1 "Calculator", branch `feat/calculator`. REQ-DEMO-003@v1 is verified and
is not touched. REQ-DEMO-004 (what Subtract does) is slice 2 and is not built
here.

## What must be true

REQ-DEMO-001@v3

1. **c1:** exactly two text boxes, two buttons and one answer label are visible
   on a single page.
2. **c2 (new):** one button shows the text "Add" and the other shows "Subtract".
3. **c3:** top to bottom: first text box, second text box, the row of buttons,
   answer label. The horizontal centre of each (the row counted as one) is the
   horizontal centre of the page.
4. **c4 (new):** Add and Subtract sit side by side on one row, Add on the left,
   with their tops level.
5. **c5 (was c3):** the page background is not plain white.
6. **c6 (was c4):** each button, each text box and the answer label has a
   background colour, a border and a font size that differ from the browser
   default for that control.

REQ-DEMO-002@v2

1. **c1:** 3 and 4, then **Add** pressed: the answer label shows 7.
2. **c2:** 0 and 5, then **Add** pressed: the answer label shows 5.

The behaviour of REQ-DEMO-002 is unchanged; only the button it names is now
"the Add button" rather than "the button".

## Approach

| File | Change |
|---|---|
| `src/index.html` | Wrap the existing `<button id="add">Add</button>` and a new `<button id="subtract" type="button">Subtract</button>` in `<div class="buttons">`, between the second text box and the answer label. |
| `src/styles.css` | `.buttons`: `display: flex; gap; width: var(--control-width)`, so the row is one centred item in the column. Each button `flex: 1`, so the two share the row equally and their tops are level. Subtract gets its own colour (e.g. a blue/grape fill with a darker edge) so a child can tell the two apart; Add keeps orange. Both keep a non-default background, border and font size. |
| `src/app.js` | No change. The Add handler already looks up `#add`. Subtract gets no handler in this slice (see "unsure"). |
| `src/calculator.js` | No change. |
| `src/server.js` | No change; no new files are served. |

## Decisions this forces

None that need an ADR. Two buttons in a flex row inside the existing column is
the obvious extension of the v2 layout.

## What I am unsure about

1. **A Subtract button that does nothing yet.** v3 puts the button on the page,
   but what it does is REQ-DEMO-004, in slice 2. Between the two slices the
   page shows a Subtract button that does nothing when pressed. That is only
   while slice 2 is unbuilt and nothing is released in between, but if you'd
   rather never have that state, slice 2 could be built straight after on the
   same branch.
2. **The heading.** `index.html` has `<h1>Add two numbers</h1>`. No requirement
   names it, but once Subtract exists it says the wrong thing. I propose to
   leave it in this slice and change it in slice 2 when subtraction works. The
   wording isn't agreed anywhere: "Add or subtract" is my guess, not the
   client's words.
3. **Subtract's colour** isn't specified beyond "differs from the browser
   default". I'll pick one that differs clearly from Add's orange; it's
   decoration, not a criterion.
