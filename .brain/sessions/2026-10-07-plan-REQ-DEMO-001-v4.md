# Plan — REQ-DEMO-001@v4 (CHG-0003, CHG-0004, CHG-0005: five buttons)

Slice 1 "Calculator", reopened. REQ-DEMO-002@v2, 003@v1 and 004@v1 are verified
and are not touched. What Multiply and Divide do is slice 3 (REQ-DEMO-006, 007);
what the close button does is slice 4 (REQ-DEMO-005). Neither is built here.

## What must be true

1. **c1:** exactly two text boxes, five buttons (four operation buttons and one
   close button) and one answer label are visible on a single page.
2. **c2:** the operation buttons read "Add", "Subtract", "Multiply", "Divide";
   the close button shows an x.
3. **c3:** top to bottom: first text box, second text box, the row of operation
   buttons, answer label; the horizontal centre of each (the row counted as one)
   is the horizontal centre of the page.
4. **c4:** Add, Subtract, Multiply, Divide sit on one row in that order, left to
   right, tops level.
5. **c5:** the close button is inside the white card, in its top right corner:
   its right edge is nearer the card's right edge than the first text box's
   right edge is, and its top is above the first text box.
6. **c6:** the page background is not plain white (unchanged).
7. **c7:** each button (now including Multiply, Divide and close), each text box
   and the answer label differ from the browser default in background colour,
   border and font size.

## Approach

| File | Change |
|---|---|
| `src/index.html` | Add `<button id="multiply" type="button">Multiply</button>` and `<button id="divide" type="button">Divide</button>` after Subtract inside `.buttons`. Add `<button id="close" type="button" aria-label="Close">×</button>` as the first child of `<main>`. |
| `src/styles.css` | `main` gets `position: relative`. `#close`: `position: absolute; top; right` inside the card's padding, a small round button with its own colour, border and font size. `.buttons button`: a smaller font size (about 1.1rem) so four words fit on one row of the 360px card without wrapping; still larger than the browser default. Multiply and Divide each get a colour distinct from Add (orange) and Subtract (grape), from the same palette. |
| `src/app.js`, `src/calculator.js`, `src/server.js` | No change. |

## Decisions this forces

None that need an ADR.

## What I am unsure about

1. **Buttons that do nothing yet.** As with Subtract last time, Multiply, Divide
   and close will be on the page before slices 3 and 4 give them behaviour.
   Nothing is released in between if slices 3 and 4 follow straight after.
2. **The x character.** The client wrote "(x)". I propose the multiplication sign
   × (U+00D7), which reads as a close mark, with the accessible name "Close" so a
   screen reader doesn't announce "times". The criterion says "shows an x"; if
   you want the letter x itself, say so.
3. **Smaller button text.** Four words in one row of a 360px card don't fit at
   today's 1.75rem. The plan shrinks the row's font to about 1.1rem. No criterion
   sets a size, only "differs from the browser default".
4. **The heading** still reads "Add two numbers". No requirement covers it.
